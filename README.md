# 文风DNA (StyleDNA)

中文 | [English](README.en.md)

> 英文标识：`style-dna-skill` / `StyleDNA`  
> 核心理念：解构笔触基因，让写作不再从零难产。沉淀个人与品牌的长效文风资产。

`StyleDNA`（文风DNA / 笔触基因）是一套用于深度蒸馏作者写作风格、认知框架与视觉排版的 Agent Skill 与工程化工具链。它不是简单的“模仿某某语气”的单次浅层提示词，而是将多篇完整历史文章深度解构为可复用、可量化、可自检的“风格规则资产集”，并通过动态智能召回、分层上下文组装与量化质检机制，实现高保真度、去 AI 腔调的受控文风复刻。

## 一、核心理念与痛点解决

### 传统 AI 仿写的典型痛点
1. **凭感觉抓表面语气**：仅提供 1-2 篇样例让模型“照着写”，模型往往只能捕捉到高频副词或表层口癖，内在论证逻辑与节奏完全失真。
2. **上下文过载与注意力衰减**：直接将 20 篇长文一股脑塞入 Prompt，导致长上下文注意力遗忘（Lost in the Middle），无法提取深层规律。
3. **严重的 AI 八股套路**：即使风格大致相似，模型输出仍频繁出现“不仅如此”、“综上所述”、“这不仅仅是一次……更是一场……”等典型机械连接词。
4. **忽视视觉排版与证据截图**：图文账号的风格很大程度体现在排版密度、加粗节奏以及截图在论证链中的承重功能，传统文字仿写完全丢失了这些维度。

### StyleDNA 的解决之道
`StyleDNA` 采用**“离线资产蒸馏 + 在线分层校准 + 量化质检拦截”**的工程化闭环，将模糊的“写作语感”拆解为 6 个客观维度的规则清单，并提供开箱即用的自动化统计与评估脚本。

## 二、六层解耦的特征蒸馏架构

`StyleDNA` 将作者风格自底向上划分为六个相互解耦的层次：

| 层次 | 分析维度 | 提取方法 | 标准产物文件 (中文 / 英文) |
| - | - | - | - |
| **L1 表层语言** | 词频偏好、平均句长、长短句比例、标点符号偏好、段落加粗密度、中英混用习惯 | 自动化脚本统计 (`analyze_corpus.py`) | `语言DNA.md` / `language-dna.md` |
| **L2 文章结构** | 开头 Hook 类型、第一转折点、正文论证架构（总分/对比/时间线/问答）、结尾收束模式 | 结构骨架标注与分类归纳 | `文章结构模板.md` / `structure-patterns.md` |
| **L3 选题逻辑** | 切入时机（早期判断/跟进复盘）、独特观察视角（当事人/系统视角）、题材优先级与禁忌 | 归纳分类与选题决策树 | `写作视角与认知框架.md` / `cognitive-framework.md` |
| **L4 素材策略** | 一手访谈 vs 公开数据、权威对象选取标准、敏感信息处理、截图在论证中的证据角色 | 深度阅读归纳 | `写作视角与认知框架.md` / `cognitive-framework.md` |
| **L5 认知框架** | 作者的底层世界观、价值判断标准、核心假设、反复出现的非显而易见命题 | 深度阅读提炼 | `写作视角与认知框架.md` / `cognitive-framework.md` |
| **L6 视觉风格** | 配图密度（篇均图数/图文间隔）、首图风格、标题层级、加粗强调节奏、色块与引用样式 | 自动化排版分析 (`analyze_visual.py`) | `视觉风格指南.md` / `visual-style-guide.md` |
| **总览集成** | 综合 L1-L6 的最高优先级约束与核心索引 | 规则整合压缩 | `Writing-DNA.md` / `Writing-DNA.md` |

- **L1 - L2（微观与宏观表达）**：解决“怎么写”。
- **L3 - L5（思维与论证灵魂）**：解决“怎么想”。
- **L6（多模态与排版视觉）**：解决“怎么呈现”。

## 三、内置自动化脚本工具链

在 `scripts/` 目录下提供了完整的 Python 脚本工具，支持标准库回退运行（无需复杂环境配置）：

### 1. 语料特征统计分析 (`scripts/analyze_corpus.py`)
自动解析指定语料目录中的 `.md` 或 `.txt` 文章，提取统计学层面的语言特征：
- 自动计算平均句长、短句（≤15字）占比、长句（≥50字）占比。
- 统计高频核心名词、动词、修饰词及常用副词。
- 统计核心标点符号分布（破折号、括号、冒号、省略号、问号、感叹号、双引号）。
- 统计每千字加粗密度及小标题平均字数。

```bash
# 运行分析并将 Markdown 报告保存至目标文件
python3 scripts/analyze_corpus.py raw/ -o 语言DNA.md

# 或以 JSON 格式导出统计数据
python3 scripts/analyze_corpus.py raw/ --json > stats.json
```

### 2. 视觉排版与图文特征提取 (`scripts/analyze_visual.py`)
解析文章中的 Markdown / HTML 排版与多模态配图标记：
- 统计篇均配图数量、每千字图片密度与图文间隔段落数。
- 分析首图/封面图存在率与配图功能说明（Alt Text 采样）。
- 统计 H1-H4 各级标题分布、引用块、代码块、分割线与列表项密度。

```bash
# 自动生成视觉风格指南初稿
python3 scripts/analyze_visual.py raw/ -o 视觉风格指南.md
```

### 3. 相似语料智能召回器 (`scripts/retrieve_context.py`)
在写作前，根据用户当前输入的写作主题、关键词或体裁，利用 BM25 算法与 `_meta` 元数据标签，自动从 `raw/` 语料库中检索出最贴近的 5 篇参考原文：
- 综合匹配文章标题、主题标签、体裁及正文语义。
- 支持按时间衰减加权（优先匹配近期风格）。
- 支持一键导出合并后的 Prompt 上下文。

```bash
# 检索 Top-5 匹配文章并在终端展示得分榜
python3 scripts/retrieve_context.py . -q "AI智能体协同工作与软件工程" -t "深度分析"

# 检索并将 5 篇参考原文合并导出为 prompt_context.md
python3 scripts/retrieve_context.py . -q "AI智能体协同" --export-context prompt_context.md
```

### 4. 风格吻合度量化评估器 (`scripts/eval_style.py`)
写作完成后对成稿进行量化质检（百分制）：
- **指标对比**：检验成稿的句长均值、长短句比例、加粗密度是否落在目标作者的基准区间内。
- **AI 味精准扫描**：内置 6 大类常见 AI 套话检测正则（空洞过渡词、夸大象征修辞、冗余填料词、机械三段论连接、过度否定排比、老套升华结尾等）。
- **扣分与改进建议**：输出诊断分析与定向修改意见。

```bash
# 评估生成文章与 语言DNA.md 的吻合度
python3 scripts/eval_style.py output_article.md -d 语言DNA.md
```

## 四、端到端完整工作流程

### 阶段一：语料准备与元数据标注
1. **收集语料**：在作者根目录下创建 `raw/` 文件夹，放入至少 20 篇代表性完整文章（建议涵盖深度分析、访谈、短评等多种体裁）。
   - 文件命名建议：`YYYY-MM-DD 内容类型 文章标题.md`
2. **建立元数据**：在 `_meta/` 目录下为每篇文章建立对应的 JSON 元数据（记录标题、日期、体裁 `article_type`、标签 `topic_tags`、开头 `hook_type`、结构 `structure_pattern` 等）。

### 阶段二：分层特征蒸馏与资产沉淀
1. **提取 L1 与 L6 数据**：
   - 运行 `python3 scripts/analyze_corpus.py raw/ -o 语言DNA.md`
   - 运行 `python3 scripts/analyze_visual.py raw/ -o 视觉风格指南.md`
2. **提取 L2 结构模板**：抽样归纳不同体裁的展开骨架，形成 `文章结构模板.md`。
3. **提取 L3-L5 认知框架**：深度提炼作者的独特观察切角、素材引用偏好与底层核心命题，形成 `写作视角与认知框架.md`。
4. **整合 Writing-DNA**：将分层结论提炼压缩，输出总控文档 `Writing-DNA.md`（控制在 4000 字以内）。

### 阶段三：智能召回与语感校准写作
1. **全量阅读蒸馏资产**：写作前必须完整阅读 `Writing-DNA.md` 及 4 份分层文档。
2. **动态召回 5 篇参考原文**：运行 `retrieve_context.py` 召回最匹配的 5 篇原文通读。
   - **核心目的**：校准规则文档无法完全量化的“微观语言呼吸感”、段落衔接方式与口语/书面语交织节奏。
3. **受控生成**：按照分层约束与本次任务指令开始起草。

### 阶段四：去 AI 痕迹与量化评估
1. **白名单去 AI 痕迹**：使用内置的 `skills/lieflat-less-ai-tone/` 规则集清理成稿。
2. **量化验收**：运行 `scripts/eval_style.py` 进行风格吻合度评分，确保得分 ≥ 70 分且无高危 AI 套话命中。

## 五、高级工作流与机制

### 海量语料分批蒸馏 (Map-Reduce)
当语料库超过 20 篇且长文居多时，单次喂给模型容易造成上下文溢出。建议采用分批工作流（详见 `references/batch_distillation.md`）：
1. **Map 阶段**：按 3-5 篇一组分批输入模型，仅提取单篇元数据与局部结构片段存入 `_meta/`。
2. **Reduce 阶段**：运行自动化分析脚本全量汇总 L1/L6 数据，并将全量 `_meta/` 注入模型归纳 L2-L5 全局规律。

### 增量更新机制 (Incremental Update)
当目标作者发布了新的 3-5 篇文章时：
1. 直接存入 `raw/` 并在 `_meta/` 中补充记录。
2. 重新运行 `analyze_corpus.py` 刷新 L1 统计基准数值。
3. 对比新文章是否出现新结构或新观点，增量补充至 `文章结构模板.md` 与 `写作视角与认知框架.md`。

### 写作前动态 Prompt 组装规范
在调用大模型写作时，建议参考 `references/prompt_assembly.md` 采用结构化拼装：
```text
[系统角色与任务说明]
   ↓
[本次写作硬性指令：主题、字数、体裁] （最高优先级）
   ↓
[目标作者 DNA 规则约束：L1 语言 + L2 结构 + L3-L5 认知 + L6 排版]
   ↓
[智能召回的 Top-5 相似原文参考片段] （语感校准层）
   ↓
[执行要求：禁止照搬具体事实 + 白名单去 AI 味质检]
```

### 规则冲突与优先级仲裁法则
在生成与后处理过程中，若遇到规则冲突，严格按以下顺序仲裁：
1. **用户明确指令**（本次指定的题材、字数、平台、语言要求）拥有最高优先级。
2. **L2 结构模板中匹配当前体裁的具体方案**。
3. **L1 语言特征与 L6 视觉排版规范**。
4. **L3-L5 认知框架**（指导观点立场与素材选择，不决定句式结构）。
5. **蒸馏产物与通用去 AI 味规则冲突时，以目标作者的蒸馏产物为准**（保留作者特有的真实语言习惯与标点偏好）。

## 六、质量验收标准 (Checklist)

一次合格的文风蒸馏与写作应满足以下标准：

- [ ] 语料库包含至少 20 篇完整文章，`_meta/` 元数据覆盖率 ≥ 80%。
- [ ] 运行 `analyze_corpus.py` 提取了客观严谨的语言统计基准。
- [ ] `文章结构模板.md` 覆盖了至少 3 种常见内容体裁。
- [ ] `写作视角与认知框架.md` 提炼出至少 3 条非显而易见的深层核心命题。
- [ ] `视觉风格指南.md` 明确了配图功能角色、图文间距与排版层级。
- [ ] `Writing-DNA.md` 精炼在 4000 字以内，无冗余空话。
- [ ] 写作前通过 `retrieve_context.py` 召回并通读了 5 篇相似题材原文。
- [ ] 成稿经 `eval_style.py` 评估，得分 ≥ 70 分且无高危 AI 套话。

1. 本项目用于学术研究、写作风格分析与个人写作资产沉淀。
2. 严禁利用本项目生成的内容冒充特定作者本人、发布虚假信息或误导公众。
3. 开源仓库内不应包含未经原作者授权的私密语料或付费文章原文。
4. 复刻的是“写作技法与论证节奏”，严禁直接搬运或抄袭原文中的事实观点与独家数据。
